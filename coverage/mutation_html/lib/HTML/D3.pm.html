 5089:     my $result = $chart->render_histogram_snippet(\@values, \%opts);
 5090: 
 5091: Generates an embeddable frequency histogram (no page shell, no CDN tag).
 5092: C<\@values> is an arrayref of numeric scalars (already extracted and
 5093: coerced by the caller).
 5094: 
 5095: Accepted C<\%opts> keys:
 5096: 
 5097: =over 4
 5098: 
 5099: =item * C<bins> (integer or C<undef>, default C<20>) - number of bins.
 5100: Pass C<undef> for automatic bin count using Sturges' rule:
 5101: C<ceil(log2(n) + 1)>.  Ignored when C<binned> is set.
 5102: 
 5103: =item * C<binned> (boolean, default 0) - treat C<$data> as pre-computed bins
 5104: rather than as raw values.  Each element is a hashref with a C<count> and
 5105: either a C<label> or a numeric C<lo>/C<hi> pair from which the label C<[lo,hi)>
 5106: is derived:
 5107: 
 5108:     { label => '[0,10)', count => 3 }
 5109:     { lo => 10, hi => 20, count => 5 }
 5110: 
 5111: The caller owns the binning, so C<d3.bin()> is never called: one bar is drawn
 5112: per entry, in the order supplied, and the supplied counts are authoritative.
 5113: 
 5114: =item * C<scheme> (string, optional) - D3 categorical colour scheme (for example
 5115: C<'tableau10'> or C<'category10'>) whose first colour is used as the bar fill
 5116: when C<color> is not given.
 5117: 
 5118: =item * C<x_label> (string, optional) - label shown below the X axis.
 5119: 
 5120: =item * C<color> (string, default C<'steelblue'>) - bar fill colour.
 5121: 
 5122: =item * C<id> (string, optional) - override the default C<svg_id> value.
 5123: 
 5124: =item * C<responsive> (boolean, optional) - SVG responsive sizing override.
 5125: 
 5126: =back
